# ⛽ Time Series Fuel Consumption Prediction

Ce projet présente une analyse de séries temporelles de la consommation de carburant au Canada de 2000 à 2022, avec modélisation ARIMA, visualisations, et une application interactive développée avec Streamlit.

---

## 📂 Contenu du projet

- `prediction.ipynb` : Notebook complet pour l’analyse exploratoire, la préparation des données, la modélisation (ARIMA) et l’évaluation des performances.
- `app.py` : Application Streamlit permettant à l’utilisateur de visualiser les données historiques et les prévisions futures de consommation.
- `annual_df.csv` et `Fuel_Consumption_2000-2022.csv` : Jeux de données utilisés pour l’analyse.
- `README.md` : Présentation du projet.

---

## 📈 Objectifs

- Comprendre les tendances de la consommation de carburant au fil du temps.
- Prévoir la consommation future à l’aide de modèles ARIMA.
- Rendre ces analyses accessibles via une interface utilisateur web.
